## Context

现有仓库使用 pnpm workspace，React/Vite 应用位于 `apps`，公共工具位于 `packages/momoUtils`。新增应用复用依赖版本，使用 SVG 和 Pointer Events 渲染交互矩形，不依赖编辑器的全局状态。

## Decisions

- 面积上限为配置宽 × 配置高；实际宽和高分别只受极限宽、极限高约束。空场景显示配置宽高的矩形，要求初始宽高不超过对应极限。
- 非空场景的外框严格等于 min(x)、min(y)、max(x + width)、max(y + height)。小矩形允许重叠，因为没有额外的不重叠规则；新增时优先寻找不重叠的合法位置，没有空间时允许重叠并提示。
- 参数通过应用按钮原子更新。若新参数无法容纳当前包围框，保留原参数和图形并显示具体错误。
- 拖动沿上一合法位置到指针目标位置的线段移动，停在遇到的首个约束边界。按活动矩形与其余包围框边缘相交的时刻分段，每段宽高线性变化，面积为二次函数。检查面积内部极大值，防止终点合法却跨过非法区域；首个非法段使用二分求最后合法位置。
- 画布支持平移、缩放、居中和键盘方向键微调。视口与算法坐标独立，视图操作不修改矩形数据。
- 界面采用浅蓝灰底色、青色包围框、多色小矩形、等宽数字和尺寸标注，主画布优先获得空间。

## Risks / Trade-offs

- 浮点边界采用最后合法二分值，避免误差让包围框超过限制。显示值做格式化，实际校验使用原始数值。
- 为保持公共算法可在 Node 中测试，提供 `@momo/utils/rectangleEscape` 子入口，避免现有 worker 入口对 `window` 的依赖。
