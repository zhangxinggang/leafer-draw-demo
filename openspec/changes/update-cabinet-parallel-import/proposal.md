# Change: 极限箱体四线程、规模保护与 JSON 参数识别

## Why

用户明确要求使用公共 worker 模块拆分为四线程计算，避免过大显示屏造成页面崩溃，并从方案 JSON 自动识别左侧参数。本提案记录本次已授权的实现范围，承接现有箱体及接线均衡变更。

## What Changes

- 行、列方向各分两个根搜索分片，通过公共模块的独立四线程池执行；汇总完整分片后才证明最优。
- 计算前限制网格规模，Worker 超时可回收并保留当前方案，大量接收卡时省略高成本图形。
- 左侧新增 JSON 输入，支持示例尾随逗号、数字字符串和接收卡模组数量最小值 1。

## Impact

- momoUtils worker、extremeCabinet；momoAlgorithm 箱体页面和 Worker；momoDraw 箱体绘图坐标。
- 保留已有常规/自由模式、四目标优先级及手动参数输入。
