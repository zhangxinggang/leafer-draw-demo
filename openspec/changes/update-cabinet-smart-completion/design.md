## Context

接线计算仍以整数模组网格作为拓扑坐标。智能补全只改变最末格子的像素坐标，避免把屏幕余量作为独立空白区。

## Goals / Non-Goals

- Goals: 按真实像素尺寸校验发送卡、网口和接收卡限制；在编辑器及大屏视口中一致绘制补全后的边缘。
- Non-Goals: 改变发送卡/接收卡/网线的优化优先级或既有 JSON 外层包装格式。

## Decisions

- 接收卡配置保存最大像素宽高；旧的模组数量字段由像素上限和模组尺寸推导，保留现有求解器输入。
- 非整除屏幕使用紧凑矩形候选，并按每种边缘尺寸实际像素校验带载和几何上限；推荐结果不声称全局最优。
- 统一的轴坐标映射将网格端点映射到显示屏实际边缘，供结构图、常规接线图和视口图使用。
- 导入流程与手动勾选调用同一补全配置处理，保证 JSON 默认开启时也同步放大接收卡尺寸。
- 屏幕信息使用视口画布分组绘制各模组规格，并按点间距绘制 LED 孔径和黑色间隙；点间距不改变求解器、接收卡或带载几何。
- LED 使用可复用的 256 × 256 间隙纹理，并通过变换保持真实点阵间距和原点；投影间距超过 128 CSS px 时直接裁剪稀疏可见孔径，避免纹理丢失细小灯珠。模组网格线只遍历可见区间。
- 屏幕信息复用画布拖动、滚轮缩放和 Home 复位交互；视图缩放时保持屏幕至少部分可见。
- 屏幕信息先将显示屏区域填黑，再绘制 `screenbg.ts` 图片和随观看距离淡化的黑色孔径遮罩。单元板使用透明填充，并以规格颜色绘制边框。
- 单元板规格图例旁的开关默认开启，并仅控制屏幕信息中的规格边框层。
- 以点间距 × 缩放得到 CSS 像素投影间距，在 1.5–12 CSS px 之间用 smoothstep 调整黑色遮罩不透明度，低于该范围显示连续原图，高于该范围显示黑底灯珠；DPR 只影响清晰度。此为远近感知近似，未标定观看米数。屏幕信息最小缩放允许任意有限正点间距进入融合区间。

Point pitch controls LED sampling and aperture coverage only; it never scales display geometry. Zero shows the image continuously, while smaller positive values reduce black gaps.

## Risks / Trade-offs

- 智能补全的紧凑矩形方案可能不是设备数量的全局最优解；界面继续标注推荐结果未证明全局最优。

## Migration Plan

已有配置可继续使用 `receiverColumns/receiverRows`；新配置优先使用接收卡像素宽高。粘贴的旧 JSON 在接收卡带载尺寸存在时读取其实际宽高。
