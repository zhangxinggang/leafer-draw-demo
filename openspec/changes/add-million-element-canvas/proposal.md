# Change: 添加百万级箱体画布与可缩放超清导出

## Why

当前“连接矩形 -> 数据测试”通过普通 JavaScript 对象数组生成数据，并为每个 `RectLine` 创建一个 Leafer `Box` 和四个 `Text` 子节点。生成 1,000,000 个箱体时，仅箱体和文字就会产生约 5,000,000 个 Leafer 节点；现有连线还会为每条边创建独立对象并监听两端属性变化。状态数组复制、全量 JSON 序列化、命中检测和单画布位图导出都会超过浏览器可接受的时间或内存范围。

需要在不改变普通画布现有功能和交互的前提下，引入面向超大场景的专用数据、渲染和导出链路，使百万箱体场景能够流畅浏览，并能导出可继续放大查看文字的图像结果。

## What Changes

- 在“连接矩形 -> 数据测试”中新增“100 万个箱体”预设，使用 1000 × 1000 网格生成 1,000,000 个逻辑箱体，并显示与现有 `RectLine` 一致的业务文字。
- 新增百万场景数据层：用分块、紧凑的 TypedArray/字典数据保存几何和复用属性，在 Worker 中完成生成、空间索引、可见性计算和批量变更，避免把百万对象反复复制到 Zustand、Leafer 树和消息字符串中。
- 新增 WebGL2 实例化渲染层与缩放级别细节（LOD）：总览绘制全部箱体轮廓或像素级聚合结果；放大后只为可见箱体绘制清晰文字、SVG/PNG 背景和连接箭头。
- 保留 Leafer UI 2.3.0 作为普通场景渲染器和活动元素交互覆盖层，确保选择、移动、缩放、编辑、撤销/重做、标尺、吸附、导入导出等现有功能不变。
- 支持最多 1,000,000 条显式箱体连接边的分层显示；总览级别允许隐藏箭头细节或使用聚合线，放大后恢复可见范围内的原始箭头。
- 新增“超清图片包”导出：按原始场景尺度在 Worker 中分块渲染为多分辨率 PNG 瓦片金字塔，并输出清单和离线查看器；用户无需把全部内容缩小到一张受浏览器尺寸限制的位图中，即可逐级放大并清楚查看文字。
- 保留现有 PNG/JPG 导出行为，普通场景及用户指定的有限区域仍走原有导出入口。
- 增加固定数据集、性能采样、视觉回归和功能回归测试，并提供大场景功能开关及自动回退路径。

## Scope Decisions

- “100 万个箱体同时显示”定义为：同一场景和同一总览视口能看到全部箱体的空间分布；当单个箱体在屏幕上不足以容纳文字像素时采用 LOD，放大到可读比例后显示完整文字和背景图。任何显示器都无法在约 1920 × 1080 像素内同时清晰呈现 1,000,000 个箱体的多行文字。
- “两两连接”按最多 1,000,000 条显式连接边（约每个箱体一条边、O(N)）验收，不按任意两个箱体都相连的完全图验收。1,000,000 个节点的完全图包含 499,999,500,000 条边，无法在客户端逐条保存或实时绘制。
- “放大后文字清晰”的全场景结果使用多分辨率瓦片图片包，而不是单张超大 PNG/JPG。以 1000 × 1000 个、每个 100 × 100 场景单位的箱体为例，原始尺度为 100,000 × 100,000 像素，已超过浏览器单 Canvas 和常见图片查看器的可靠上限。
- WebAssembly/CanvasKit 只在基准分析证明 Worker 中的索引、排版或编码仍是瓶颈时引入；首选 WebGL2 实例化渲染，避免不必要的包体、启动时间和双份内存成本。

## Impact

- **Affected specs**:
  - `large-canvas-rendering`（新增能力）
  - `large-canvas-export`（新增能力）
- **Affected code**:
  - `apps/momoEditor/src/components/SuperEditor/mock/generateRect.ts`
  - `apps/momoEditor/src/components/SuperEditor/layout/RightPanel/CanvasProperties/`
  - `apps/momoEditor/src/components/SuperEditor/layout/TopBar/`
  - `apps/momoEditor/src/components/SuperEditor/store/`
  - `packages/momoDraw/src/renderer/`
  - `packages/momoDraw/src/types/`
- **Compatibility**:
  - 普通场景继续使用现有 Leafer UI 2.3.0 渲染和导出链路。
  - 大场景通过独立开关和阈值启用；WebGL2 不可用或初始化失败时回退普通模式并明确提示百万级性能不受保障。
  - 不改变现有组件 JSON 字段语义；大场景新增版本化的分块存储/流式导入导出格式。
- **Operational impact**:
  - 增加 GPU 资源、Worker、字体/图片图集和瓦片缓存的生命周期管理。
  - 超清全场景导出可能产生数万张瓦片和较大的 ZIP 文件，UI 必须显示空间预估、进度、取消和失败原因。
