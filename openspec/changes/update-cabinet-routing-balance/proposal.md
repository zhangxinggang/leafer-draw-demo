# Change: 箱体自由接线、接收卡均衡与分层说明

## Why

用户要求接收卡以完整单元板组合且宽高分别不超过配置，在设备数量最优后均衡每张发送卡的接收卡数量，并提供自由接线和可辨认的叠加结构。

## What Changes

- 保持可缩小的接收卡整数宽高上限。
- 优化顺序为发送卡数、接收卡数、接收卡分配平方和、网线数；固定前两项时平方和最小等价于方差最小。
- 常规模式保留网线矩形分区；自由模式允许不规则覆盖，但同一网口必须沿共享边相邻的接收卡连续连接，发送卡仍保持矩形覆盖及原带载/网口限制。
- 输入区右侧提供常规/自由 Tab；Tab 上方使用 momoDraw / Leafer 展示正视叠加网格、实际尺寸及右侧颜色图例，与左侧显示屏参数顶端对齐。

## Impact

- 修改 extreme-cabinet 算法、审计、Worker 状态及页面；复用原生 Leafer 渲染。
- 本提案记录用户当前目标中已明确授权的实现范围；排序及发送卡覆盖语义采用已说明的上述默认值。
- 本变更承接尚未归档的 `add-extreme-cabinet`，其 MODIFIED 需求替代该变更中原有的数量优先级和接收卡颜色规则。
