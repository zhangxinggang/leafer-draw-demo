# Change: 新增极限箱体算法与接线图

## Why

用户明确要求在算法页第二个卡片实现极限箱体，并按发送卡、接收卡、网线数量依次最小化。本变更按该直接实现授权实施。

## What Changes

- 新增参数表单、模组尺寸换算、真实发送卡带载、分层接线图和数量统计。
- 在整数模组网格上进行精确字典序优化，覆盖任意矩形分区（含非切割式布局）。
- 使用构造解、面积及几何下界、状态缓存和剪枝加速；Worker 返回可行解并继续证明最优。
- 区分已证明最优与仍在搜索；不把超时或启发式结果标为全局最优。
- 按用户参考图加入发送卡名称、接收卡尺寸/模组文案、编号圆形起点、边界方向箭头和方形终点；不同发送卡使用不同颜色，支持展开查看。

## Impact

- Affected specs: `extreme-cabinet`
- Affected code: `apps/momoAlgorithm`、`packages/momoUtils/src/extremeCabinet`、公共导出与 README。
