# 重构编辑器界面布局 - 完整计划

## 项目结构分析

当前项目基于 Leafer UI 构建，核心渲染逻辑在 `src/components/SuperEditor/driver/` 和 `src/components/SuperEditor/editor/canvas/` 中。使用 Zustand 进行状态管理。

## 核心改造目标

1. 重新组织界面为四区域布局（顶部快捷菜单、左侧元素选择菜单、中间画布渲染区域、右侧属性面板）
2. 将核心渲染逻辑独立为core模块，便于后续作为npm包使用，支持无界面渲染
3. 支持拖拽添加元素、多选批量操作、对齐功能、标尺和辅助线

## 实施步骤

### 1. 核心渲染逻辑独立化

- **创建独立渲染模块** `src/core/` 目录
  - 将 `driver/` 目录移动到 `src/core/renderer/`
  - 将 `editor/canvas/render.tsx` 和 `generator.ts` 移动到 `src/core/`
  - 将 `interface/cmp.ts` 移动到 `src/core/types/`
  - 将渲染相关的工具函数移动到 `src/core/utils/`
  - 创建 `src/core/index.ts` 作为核心模块的统一导出
- **保持核心逻辑无UI依赖**：
  - 确保核心模块不依赖 React 组件，仅提供渲染函数和类型定义
  - 支持无界面渲染（headless），提供独立的API供外部调用
  - 核心模块提供纯函数和类型，UI组件调用核心模块的API

### 2. 重构主布局结构

- **创建新布局组件** `src/components/SuperEditor/layout/`
  - `TopBar.tsx` - 顶部快捷菜单
  - `LeftSidebar.tsx` - 左侧元素选择菜单
  - `CanvasArea.tsx` - 中间画布渲染区域（包装原有Canvas组件）
  - `RightPanel.tsx` - 右侧属性面板
  - `index.tsx` - 主布局容器
- **更新** `src/components/SuperEditor/editor/index.tsx` 使用新布局
- **支持暗色主题**：全局可切换，支持持久化

### 3. 顶部快捷菜单实现

- **功能按钮**：
  - 选中（Select）、移动（Dragger）、撤销、重做
  - 放大缩小自适应（Auto/Fit按钮）
  - 对齐方式（左、中、右、上、中、下）- 多选时启用，单选时置灰
    - 左对齐：以最左元素为准，其他元素对齐到最左元素的左边界
    - 右对齐：以最右元素为准
    - 上对齐：以最上元素为准
    - 下对齐：以最下元素为准
    - 水平居中：以选中元素的整体边界框中心为准
    - 垂直居中：以选中元素的整体边界框中心为准
    - 对齐操作支持撤销/重做，对齐到参考边界
  - 导出（导出图片-原有功能、导出JSON）、导入JSON、保存按钮（右侧，使用原有功能）
- **对齐功能实现**：在 `store/model.ts` 中添加 `alignCmps` 方法
- **文件**：`src/components/SuperEditor/layout/TopBar.tsx`

### 4. 左侧元素选择菜单实现

- **布局结构**：
  - 左侧：一级菜单（文本、元素、图片），默认选中"元素"，宽度60px，可拖动调整（最小100px）
  - 右侧：紧挨着一级菜单显示对应的二级菜单面板，默认宽度310px，可拖动调整（最小100px）
- **二级菜单面板**：
  - **文本**：
    - 基本文本（无任何设置）
    - 炫彩文本：渐变文字、描边文字、阴影文字、发光文字等预设样式，每个样式有预览，支持可配置参数
      - 渐变文字：线性渐变（从左到右），颜色 `#FF6B6B` → `#4ECDC4`，角度0度
      - 描边文字：描边宽度2px，颜色 `#000000`，位置外部
      - 阴影文字：模糊4px，偏移2px, 2px，颜色 `rgba(0, 0, 0, 0.3)`
      - 发光文字：模糊8px，颜色 `#00FFFF`，强度1
  - **元素**：矩形、圆形、线条、箭头等（原有toolbar功能，显示图标和名称）
  - **图片**：
    - 可用图片列表（缩略图），数据来源：手动配置初始列表（src/assets/images下的图片，分类为"默认"）
    - 支持分类和搜索
    - 选择图片按钮（支持多选）
    - 本地上传图片，默认名称"临时图片+数字"（不重复），自动添加到list，分类为"临时"
    - 图片列表格式：`{id, name, src}`，用户可自定义分类
- **一级标题分类**：每个二级菜单都有分类标题，便于后续扩展
- **添加元素方式**：
  - **双击**：双击菜单项，在画布可视区正中间添加元素（元素中心点在画布中心），使用预设尺寸
    - 文本：200x50，字体16px
    - 矩形：100x100
    - 圆形：半径100（即200x200）
    - 线条：默认100
    - 箭头：默认100
  - **拖拽**：从菜单项拖拽到画布，显示预览（跟随鼠标的元素预览），在释放位置添加元素（元素中心点在释放位置，几何中心：x + width/2, y + height/2）
- **文件**：
  - `src/components/SuperEditor/layout/LeftSidebar.tsx`
  - `src/components/SuperEditor/layout/LeftSidebar/TextPanel.tsx`
  - `src/components/SuperEditor/layout/LeftSidebar/ElementPanel.tsx`
  - `src/components/SuperEditor/layout/LeftSidebar/ImagePanel.tsx`

### 5. 右侧属性面板增强

- **无选中元素时**：显示画布属性
  - 画布名称输入框（持久化）
  - 背景颜色设置（持久化，应用到画布的fill属性，导出时包含背景色）
  - 画布尺寸设置：宽高两个输入框，默认宽800，高600
  - 标尺设置：
    - 开启/关闭标尺开关
    - 刻度间隔设置（如10px、50px、100px）
    - 辅助线吸附开关
    - 辅助线吸附距离设置（默认5px）
    - 辅助线列表（显示所有辅助线，支持锁定/解锁、删除）
- **单选元素时**：显示原有元素属性面板
- **多选元素时**：显示批量操作面板
  - 颜色设置（仅对支持的元素生效，不支持则隐藏该选项）
  - 描边设置、描边宽度（仅对支持的元素生效，不支持则隐藏该选项）
  - 透明度、图层顺序
  - 复制、删除
  - 批量操作支持撤销/重做
- **文件**：
  - `src/components/SuperEditor/layout/RightPanel.tsx`
  - `src/components/SuperEditor/layout/RightPanel/CanvasProperties.tsx`
  - `src/components/SuperEditor/layout/RightPanel/ElementProperties.tsx`
  - `src/components/SuperEditor/layout/RightPanel/BatchProperties.tsx`

### 6. 中间画布区域增强

- **标尺功能**：
  - 在画布顶部和左侧显示标尺（通过右侧属性面板控制显示/隐藏）

## 注意事项

1. 保持向后兼容：确保现有功能不受影响
2. 核心逻辑独立：渲染相关代码不依赖UI组件，可以独立作为npm包使用，支持无界面渲染
3. 性能优化：多选批量操作时注意性能，使用防抖/节流
4. 类型安全：保持TypeScript类型完整性
5. 标尺和辅助线：需要计算画布坐标和屏幕坐标的转换，实现吸附功能
6. 双击和拖拽：需要区分双击和拖拽事件，双击时计算画布可视区中心点，使用预设尺寸；拖拽时显示预览
7. 持久化：画布名称、背景色、暗色主题使用localStorage持久化
8. 背景色：应用到画布的fill属性，导出时包含背景色
9. 元素中心点：使用几何中心（x + width/2, y + height/2）
10. 批量操作：不支持某个属性时隐藏该选项，支持撤销/重做
11. 图片管理：手动配置初始列表，支持分类、搜索、上传，上传图片命名规则"临时图片+数字"（不重复）
12. 导出功能：导出图片（原有功能）、导出JSON、导入JSON（完全替换store）
13. 暗色主题：全局可切换，支持持久化
14. 菜单宽度：左侧菜单可拖动调整，最小100px，不持久化
15. 辅助线吸附距离：默认5px，可在右侧属性面板中设置
