## 需求

```
算法页面，第二个卡片为：极限箱体
显示屏（就是矩形，方便区分），可设置宽，高
模组（就是矩形，方便区分），可设置宽，高
接收卡（就是矩形，方便区分），可设置 模组宽数量，模组高数量，例如输入2模组宽数量，即 模组的宽2，UI上需要计算出来
发送卡（就是矩形，方便区分），可设置极限宽，极限高，极限带载，网口数量（就是一个限制），发送卡的真实极限带载，必须是极限带载 与 网口数量网口带载 的最小值
网口带载（就是其他的矩形面积），可输入值，默认 650000
用户将信息输入好了后，在UI上
显示屏在最底部灰色显示，模组则从显示屏的左顶点还是铺满显示屏，注意模组不能超出显示屏，也不能与显示屏交叉；
在模组上方显示接收卡，即接收卡框选哪些模组，最外层是发送卡，即发送卡框选哪些接收卡，同时接收卡使用箭头线进行连接，接收卡连接的箭头从接收卡中间开始连接需要标注起点和终点；
每条连接线（网线）使用不同的颜色进行区分，不同的发送卡使用不同的边框颜色，背景透明需要看清下方框选的接收卡；
每个接收卡内部，标注发送卡的序号，箭头连线的序号，以及当前发送卡框选的网线里第几根
必须满足的条件：
1. 箭头线连接的接收卡必须可以组成一个矩形，组成的矩形算一根网线
2. 箭头线连接的接收卡，面积总和不能超过网口带载
3. 接收卡的宽高可以是动态的，但是必须是模组的宽高的倍数
4. 发送卡框选的接收卡里，箭头线连接的网口数量，不能超过发送卡设置的网口数量
5. 发送卡不能超过设置极限宽，极限高，极限带载
6. 整个绘制过程，首先要达到 发送卡的使用数量最少，其次接收卡的数量使用最少，其次是网线的使用数量最少
结果上显示
模组的数量，接收卡的数量，发送卡的数量，网线的数量
请实现这么一套算法实现上述需求，必须达到第6点，并且还要保障快速给出结果
```
